# ZimConnect 🇿🇼

**ZimConnect** is the all-in-one platform for Zimbabwe. 
Jobs. Events. Store. TV. Podcast. Radio. All in one app.

## Features
- 💼 **Jobs**: Find work across Zimbabwe
- 📅 **Events**: Discover what's happening near you  
- 🛍️ **Store**: Support Zim businesses
- 📺 **ZimConnect TV**: Video podcasts and interviews
- 🎙️ **Street Gear Podcast**: Audio stories
- 📻 **Groove FM Radio**: Live 24/7 streaming

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Progressive Web App - Installable on phone
- GitHub Pages + GitHub Actions for auto-deploy
- Hosted audio/video via Archive.org

## How to Install
1. Open `zimconnect.com` on your phone
2. Chrome > Menu > "Install App"
3. Use offline with the bird icon on your home screen
